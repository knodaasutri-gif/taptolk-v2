# TapTalk（taptolk-v2） 要件定義書 & システム設計シート

## 1. 概要
本ドキュメントは、聴覚障害者および会話補助を必要とするユーザー向けのコミュニケーション補助Webアプリケーション「TapTalk」の要件定義および設計仕様をまとめたものです。

## 2. 開発背景と目的
* **背景**: 聴覚障害のあるユーザーが日常会話や仕事上のやり取り（朝礼、指示受け、確認等）を行う際、音声入力や筆談、定型カードの提示など多様な入力方法をスムーズに切り替える必要がある。
* **目的**: 定型文カードのタップ、音声入力、自由文字入力を一元化し、相手に素早く意思や質問を伝えられるアクセシブルなコミュニケーションインターフェースを提供する。

## 3. システム要件

### 3.1 機能要件

| No. | 機能分類 | 機能名 | 詳細・仕様 |
|---|---|---|---|
| F-01 | 表示領域 | テキスト表示エリア | 入力された音声テキスト、定型文カードの文面、自由入力テキストを画面上部に大きく表示する。 |
| F-02 | 定型文機能 | タップカード | カテゴリごとに分類された定型文カード。タップすることでテキスト表示エリアに即座に文字を出力し、音声読み上げ（TTS）を実行する。 |
| F-03 | 定型文機能 | お気に入り（星マーク） | よく使うカードをお気に入り登録し、優先表示する。 |
| F-04 | 入力機能 | 音声入力 | マイクを通じてユーザーの発話内容をリアルタイムでテキスト化（音声認識）する。 |
| F-05 | 入力機能 | 自由入力 | キーボードによる任意のテキスト入力。 |
| F-06 | 入力機能 | 辞書機能 | 独自の定型語句やよく使う表現を管理・挿入する。 |
| F-07 | 定型文管理 | カード作成・編集 | 新しいタップカードの追加および既存カードの表示内容・カテゴリの編集。 |
| F-08 | ユーザー補助 | 音量確認バナー | カード読み上げ時の音量不足トラブルを防ぐため、画面最上部にスマホの音量変更を促す注意メッセージを常時表示する。 |
| F-09 | ブラウザ識別 | ファビコン表示 | ブラウザのタブやホーム画面追加時にアプリ識別用アイコン（マイク＋吹き出し）を表示する。 |

### 3.2 非機能要件
* **UI/UX (アクセシビリティ)**: 押しやすい大きなボタン配置と直感的な配色（カテゴリごとの色分け）。視認性の高い文字サイズと十分なコントラスト。
* **動作環境**: モバイルブラウザ（iOS Safari / Android Chrome）に最適化。応答速度が速く、1タップで即時反映される操作感。
* **インフラ / ホスティング**: GitHub Pages を利用した静的Web配信。

* `index.html`: アプリの全体構造、ボタン、表示領域、モーダルダイアログの定義。
